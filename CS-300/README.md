# CS 300: Data Structures and Algorithms
Melanie Jarrard

## What was the problem you were solving in the projects for this course?

The projects focused on creating an advising assistance program for ABC University. Academic advisors needed a way to load course information, display all computer science courses in alphanumeric order, and look up a specific course’s title and prerequisites. Project One involved comparing possible data structures and analyzing their runtime and memory requirements. Project Two involved implementing the program in C++.

## How did you approach the problem?

I started by breaking the requirements into smaller tasks, including reading the course file, storing course information, sorting courses, and searching for individual courses. I compared vectors, hash tables, and binary search trees to understand the advantages and limitations of each option. Understanding data structures is important because the way information is stored affects the efficiency of searching, inserting, and displaying data. The analysis helped me connect my design choices to the program’s requirements.

## How did you overcome any roadblocks you encountered?

One challenge was connecting the pseudocode and runtime analysis to a working program. I approached this by working through individual operations and checking how information moved from the input file into the data structure and then into the displayed results. Breaking the program into smaller parts made it easier to identify problems with file parsing, searching, and output order. Reviewing the relationship between course numbers and prerequisites also helped me understand the importance of validating input.

## How has your work on this project expanded your approach to designing software and developing programs?

These projects taught me to evaluate design choices before beginning implementation. I now consider how a program will access its data, which operations will happen most frequently, and how performance could change as the amount of data increases. Writing pseudocode and comparing runtime and memory requirements helped me approach development more deliberately instead of choosing the first solution that seemed workable.

## How has your work on this project evolved the way you write programs that are maintainable, readable, and adaptable?

I gained a better understanding of the value of separating responsibilities into focused functions, using descriptive names, and keeping data organized consistently. Separating file loading, menu interaction, searching, and course output makes the program easier to understand and update. I also learned that input validation and clear error messages help make a program more reliable. These practices will help me develop software that is easier to debug, maintain, and adapt to future requirements.
