# CS255 - Systems  Analysis and Design

## Course Overview

This course is focused on software analysis, requirements gathering, system design,and UML modeling. The primary project involved designing the DriverPass system, a platform that helps students prepare for DMV examinations and schedule driving lessons.

## Skills Demonstrated

- Requirements Analysis
- Systems Design
- UML Modeling
- Use Case Diagrams
- Activity Diagrams
- Sequence Diagrams
- Business Requirements Documentation
- Project Planning
- Agile Development Conceots
- Technical Communication

## Major Project: DriverPass

The DriverPass project required gathering stakeholder requirements, identifying system functionality, developing UML models, and creating detailed design documentation. The project emphasized understanding user needs before software development begins.

## Project Artifacts

- Business Requirements Documents
- System Design Document
- Use Case Diagram
- Activity Diagram
- Sequence Diagram
- Client Presentation

## Reflection

This course strengthened my understanding of the software development lifecycle and the importance of planning before implementation. I gained experience translating business needs into technical requirements and creating models that communicate system behavior and functionality to both technical and non technical stakeholders.
